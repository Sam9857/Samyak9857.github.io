04 · Projects

Things I’m building.

IN DEVELOPMENT

Bit Sentinel – Threat Detection System

// real-time log analysis & threat prevention dashboard

A Flask-based security dashboard that ingests server logs and live traffic, flags attacks using signature and behavioural analysis, scores every IP from 0–100, and can automatically block malicious sources. Results stream to the dashboard in real time.

The behavioural engine is deliberately rule-based and explainable: each verdict comes with a plain-English reason, so every decision is auditable.

  • Signature detection for SQL injection, XSS and path traversal
  • Behavioural detection of brute force and high-frequency / DDoS-style traffic
  • Weighted 0–100 risk score with explainable reasoning
  • Auto-block engine with configurable threshold, plus whitelist & blacklist
  • Per-IP sliding-window rate limiter
  • Log upload (.log / .txt / .csv) — Apache/Nginx & simple formats
  • Live monitor: simulation, self-tap and log-tail modes
  • Server-Sent Events dashboard, IP detail view, JSON report export
